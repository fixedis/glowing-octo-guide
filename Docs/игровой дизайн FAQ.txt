## Часть 1. Концепция, визуал, карты, камера, переходы, HUD

> Статус: продолжает и углубляет FAQ v9.0, не заменяет его.
> v9.0 = правила игры; v9.1 = как это выглядит, ощущается и работает.

### 0. Сквозные принципы

#### 0.1 Одна визуальная реализация — все контексты [принцип №0]

Любой 3D/2D-объект используется везде, где возможно, без параллельных вариаций:
- модель корабля из конструктора = модель в бою = модель на карте = модель в реплее;
- различаются только detail-уровни (`icon` / `thumbnail` / `full` по регламенту движка);
- одна планета = одна 3D-оболочка на карте созвездия, в окне планеты, в бомбардировке.

#### 0.2 Никаких переключений страниц [Q11]

Все переходы между картами — перелёт камеры:
```text
глобальная → галактика → созвездие → планета и обратно.
```
Игрок не видит «смен экрана», только непрерывное движение.

#### 0.3 Визуальные сущности — data-driven [Q42, Q43]

Типы звёзд, туннелей, нерасчищенных квадратов, препятствий — ассеты.
Добавил файл → появилось в игре. Движок не знает конкретных типов.

#### 0.4 Адаптивный интерфейс [Q4]

- **ПК** — элегантный, простой, «дорогой», интуитивный sci-fi HUD (минимализм + информативность Stellaris-like).
- **Мобильные** — упрощённый минимализм без визуального шума.

### 1. Общий визуальный стиль

#### 1.1 Арт-направление: реалистичный космос [Q1=A]

Серьёзный, тёмный, детальный, референсы Stellaris / EVE.

#### 1.2 Палитра космоса: тёмно-синий [Q2=B]

Космос не чёрный: тёмно-синие градиенты, туманности, подсветка.
Объекты и UI не теряются, атмосфера сохраняется.

#### 1.3 Цветовая семантика [Q3=да]

| Объект / состояние | Цвет |
|---|---|
| Игрок | синий / голубой |
| Союзник | зелёный |
| Свои захваченные системы (общая обводка) [Q47] | союзный голубой |
| Враг | красный |
| Нейтрал | серый |
| Пираты | оранжевый |
| Аномалии | фиолетовый |
| Левиафаны | ярко-фиолетовый / багровый |
| Угасшие империи | золотой / бирюзовый |
| ИИ-апокалипсис | багрово-чёрный / токсично-красный |
| Ресурсы | жёлтый / янтарный |
| Опасность | красный пульсирующий |
| Исследование | голубой |
| Врата | бирюзовый |

Цвета отношений к чужим фракциям = цвета обводок территорий [Q47].

#### 1.4 UI-стиль [Q4=D, ПК=A+C]

Тонкие полупрозрачные панели, аккуратные рамки, минимум шума.
На ПК — плотность информации как в Stellaris, но визуально «просто и дорого».
Всё интуитивно: игрок всегда понимает, что происходит.

### 2. Карты и камера

#### 2.1 Уровень 1 — глобальная карта галактик [Q5=C, Q6=B+D]

- Псевдо-3D изометрия с лёгким наклоном и параллаксом.
- Сетка 100×100 на старте, далее бесконечно.
- Сетка видна, но слабая — карта не должна выглядеть таблицей.
- Галактики — светящиеся узлы; неисследованное — тёмный туман с шумом.
- Ранее виденный, но потерянный из обзора объект — тусклая серая версия с пометкой «устаревшие данные».
- Доступ — только после изучения структуры древней цивилизации (v9.0).

#### 2.2 Уровень 2 — карта галактики [Q7=C, Q8=C]

Гибрид узловой схемы и красивого космоса: системы — не точки, а мини-звёзды своего типа:
- обычная;
- двойная;
- пульсар;
- чёрная дыра;
- нейтронная звезда;
- красный гигант.

Тип читается визуально до открытия деталей.

Туннели видимы, но не яркие, чтобы не выпадать из реалистичности космоса [Q8-уточнение].

| Состояние туннеля | Вид |
|---|---|
| Обычный | тонкая приглушённо-голубая линия |
| С вратами | бирюзовая линия + иконки врат |
| Повреждённый | прерывистая оранжевая |
| Заблокированный | красная с замком |
| Опасный | фиолетовая / багровая пульсация |
| Альянсовый маршрут | зелёная подсветка |

Туман войны + общая видимость альянса (v9.0).

#### 2.3 Уровень 3 — карта созвездия [Q9=B+C, Q10=C]

- 3D через React Three Fiber.
- Почти плоская эклиптика с лёгкими наклонами орбит для красоты.
- Орбиты — тонкие линии, пространство читается.
- Звезда в центре (тип из 2.2).
- Планеты 2–5, спутники 1–3, пояса астероидов (v9.0).
- Орбитальное движение планет — фоновое, атмосферное.
- Бой происходит в тактической зоне и не зависит от положения планет на орбитах [Q10=C].
- Выделение планеты — бирюзовое кольцо-подсветка (референс-кадр 2).
- Флоты — модели кораблей (те же, что в конструкторе и бою, принцип 0.1).

#### 2.4 Уровень 4 — карта планеты [Q11, Q12]

- Как в Stellaris, но с живой 3D-планетой справа/в центре.
- Окно построек — левее середины [Q11].
- Вход: клик по планете на карте созвездия → экран быстро подлетает к планете → открывается окно построек.
- Без переключения страниц (принцип 0.2).
- Слоты, расчистки, население, оборона — в окне планеты [Q12].
- Поверхность планеты визуально реагирует: постройки, воронки, пожары (см. раздел 6).

### 3. Переходы: CameraDirector + TransitionController [Q44, Q45]

Единый механизм на все 4 карты, одна реализация (принцип 0.1).

#### Сценарий ПК (0.8–1.2 с)

1. Старт перехода: лёгкий motion blur + fade в тёмно-синий космос.
2. Туннелирование камеры через гиперпространство (короткий warp-эффект).
3. Хлебные крошки пути: показывается текущий уровень и предыдущий (глобальная → галактика → созвездие → планета).
4. Прибытие: плавное fade-in новой сцены + лёгкий zoom на целевую систему/планету.
5. Параллельно идёт загрузка данных новой сцены.

#### Сценарий мобильный

Упрощённо: blur + fade ≈ 0.5 с, без полос (бережём GPU).

#### Правила переходов

- Данные грузятся параллельно; не успели — полосы длятся дольше, чёрного экрана нет никогда.
- Обратный переход — «отлёт» с тем же туннелированием + хлебные крошки пути (глобальная → … → планета) [Q45].
- Переход маскирует смену рендерера (Canvas ↔ R3F) — игрок этого не видит.

### 5. HUD и информационные панели [Q4, Q55]

Единый принцип контекстных блоков (тот же, что в конструкторе):
- слева — контекстный список действий/объектов;
- справа — характеристики выбранного.

#### Верхняя панель

Ресурсы: железо, минералы, газ, энергия, кредиты, золото.
Лимиты и дефициты подсвечиваются красным при нехватке.

#### Правая панель выбранного объекта

Характеристики, состояние, кнопки действий.

#### Трей событий [Q55]

- События лежат в трее игры, видимы.
- Важные события не ограничены по времени.
- Журнал с фильтрами.

#### Тултипы

- Наведение / тап — краткая справка.
- Полное описание — по клику.

#### Уведомления

- О боях и атаках — в трей + маркер на карте.

### 6. Планета: постройки и бомбардировка [Q11–Q13, Q40–Q43]

#### 6.1 Здания

- У здания есть уровни и HP.
- Чем выше уровень, тем больше HP [Q13].
- HP падает до нуля → здание становится на уровень ниже, HP сбрасывается до максимума нового уровня, выработка = текущему уровню [Q41].
- Все уровни упали → появляется нерасчищенный квадрат «Разрушенная постройка».

#### 6.2 Бомбардировка — визуал [Q13]

- Корабли висят над планетой.
- На поверхности мини-взрывы.
- Население тает в численности.
- Обороняющиеся теряют жизни и погибают постепенно.
- Режимы флота: бомбардировка / бой / следование / стоянка.
- Ввязался в бой → режим переключается на бой [Q40].
- Режимы бомбардировки: точечный (здания/оборона), террор (население), тотальный [Q40].

#### 6.3 Нерасчищенные квадраты — сущности [Q42, Q43]

Некоторые расчищаются сразу, некоторые — только после исследования технологии.

**Базовые типы:**
- обломки (сразу);
- токсичные (технология);
- кратеры (технология);
- биозаражение (технология);
- горы;
- останки древней цивилизации;
- животная фауна;
- магнитные поля;
- природные явления;
- деревья.

Список открыт: новый тип = новый ассет, движок не правится.

- Расчистка даёт немного лома в зависимости от типа квадрата [Q43].
- Каждая 5-я расчистка исчезает и навсегда уменьшает общее количество построек планеты (v9.0).

## Часть 2. Корабли, конструктор, ИИ-карточки, доктрины, запекание, бой, ремонт, бомбардировка, абордаж, наземные операции

### 8. Корабль и конструктор

#### 8.1 Структура: секции-модули

Корабль состоит из секций: носовая / средние / хвостовая [Q14].

Количество средних секций зависит от силы класса:
- корвет — всего 1 модуль;
- малые корабли могут иметь один модуль;
- крейсер — нос + середина + хвост;
- линкор / авианосец — больше;
- титан — ещё больше.

Раскладка задаётся классом как ассетом класса:
- класс определяет типы секций на выбор и их количество;
- игрок выбирает конкретные секции из доступных типов [Q21=A].

Класс выше открывается исследованием.  
Корвет — первый и бесплатный.

Новые классы и секции добавляются без правок ядра, data-driven [принцип 0.3 из Части 1].

Крутые секции также могут выпадать в выборе исследований.

#### 8.2 Ячейки модулей и масштабирование

У каждой секции есть ячейки четырёх типов:
1. вооружение — универсальные ячейки плюс «вес» оружия;
2. броня;
3. энергетическая броня;
4. спецоборудование.

Базовая таблица масштабирования.  
Коэффициент ориентировочный: ×2–3 на каждый класс. Точные числа — баланс.

| Класс | Секции | Ячейки оружия на секцию | Ячейки защиты | Спец |
|---|---:|---:|---:|---:|
| Малый: корвет, истребитель | 1 | 1 | 1 | 0–1 |
| Средний: крейсер | 3 | 2–3 | 2–3 | 1 |
| Крупный: линкор, авианосец, осадный | 4–5 | 6–8 | 6 | 2 |
| Мега: титан и другие | 6+ | 12+ | 9+ | 2 + ячейка сверхтехнологии |

Оружие и вес ячеек [Q23=A]:
- ячейки универсальные;
- оружие занимает 1–4+ ячейки в зависимости от технологии и размера;
- тяжёлые орудия могут не помещаться на малые, средние и даже крупные секции;
- самые тяжёлые орудия встают только в самые большие секции.

Вес:
- у каждой секции есть собственный вес и переносимый вес;
- совокупный вес против мощности двигателя влияет только на скорость;
- перегруз по массе не блокирует сохранение корабля.

HP:
- у модулей есть собственные HP;
- они входят в общий пул корабля;
- пулы обычной брони и энергетической брони считаются раздельно.

#### 8.3 Энергия: числовое «требуется / доступно»

Энергия — не проценты, а абсолютные числа.

Формула смысла:

```text
требуется = секции + модули + оружие
доступно = реактор + модули усиления энергии
```

Пример:
- секции: 988;
- модули: 700;
- оружие: 700;
- итого требуется: 2388;
- реактор с усилением даёт: 2103;
- результат: создание и сохранение корабля невозможно.

Блокирует только энергия.  
Перегруз по массе не блокирует сохранение, а влияет только на скорость.

#### 8.4 Двигатели

На каждом корабле всегда два двигателя:
1. полётный;
2. прыжковый.

Прыжок:
- зарядка всегда требует времени;
- прыжок требует газа;
- расход газа = функция числа кораблей и дистанции;
- газ тратится только на прыжки;
- в бою газ не влияет.

Скорость:
- скорость полёта зависит от уровня полётного двигателя;
- скорость прыжка зависит от уровня прыжкового двигателя;
- скорость флота = скорость самого медленного корабля.

#### 8.5 ИИ-ячейка и ячейка сверхтехнологии

У каждого корабля есть настраиваемая ИИ-ячейка.  
Это одна из главных механик управления боем. См. раздел 12.

У огромных кораблей есть специальная ячейка сверхтехнологии, если технология изучена.

Примеры сверхтехнологий:
- подавитель щитов;
- подавитель брони;
- подавитель межпространственных прыжков;
- ауры усиления своих кораблей;
- ауры ослабления вражеских кораблей.

Подавитель межпространственных прыжков:
- пока в системе жив носитель, у вражеских флотов растёт время зарядки прыжка.

#### 8.6 Интерфейс конструктора

Слева:
- блок выбора корабля для постройки: крейсер, авианосец и т.д.

По центру:
- 3D-проекция корабля;
- можно приблизить и покрутить;
- используется та же оболочка, что в бою и на картах [принцип 0.1];
- 3D доступно сразу, но модели могут быть «грубыми»;
- усложнение моделей не должно ломать движок [Q15=A].

Сверху:
- выбор секций;
- кнопки замены секций;
- в секциях отображаются ячейки вооружения.

Клик по ячейке вооружения:
- левый блок заменяется списком доступного вооружения именно для этой ячейки;
- оружие можно перетащить;
- если оружие влезает по весу ячеек, оно устанавливается.

Снизу:
- ячейки секций для брони;
- ячейки для энергетической брони;
- ячейки для спецтехнологий.

Клик по такой ячейке:
- левый блок показывает доступные улучшения для вставки.

Правило:
- левый блок всегда содержит только то, что доступно для выбранной ячейки: оружие, броня или спецоборудование.

Справа:
- характеристики;
- двигатели;
- ИИ;
- реактор;
- модули усиления энергии;
- дополнительные ячейки.

Проекты кораблей:
- сохранять;
- удалять;
- менять;
- бесплатно публиковать;
- лайки;
- топ по скачиваниям и лайкам;
- лидеры публикаций.

Если сохранённый проект изменён в конструкторе:
- у флота с этими кораблями появляется значок:
  ```text
  требуется верфь для обновления по последним технологиям
  ```

### 9. Характеристики, урон, ремонт, запекание

#### 9.1 Пулы и порядок урона

Порядок получения урона:

```text
энергетическая броня → обычная броня → HP
```

Это три раздельных пула:
1. энергетическая броня;
2. обычная броня;
3. HP, то есть структура и экипаж.

Потеря HP не меняет характеристик корабля, кроме самих пулов брони и HP.

#### 9.2 Регенерация и ремонт

В бою регенерации нет никакой.

Энергетическая броня:
- восстанавливается вне боя;
- бесплатно;
- со временем.

Броня и HP:
- восстанавливаются только ремонтом.

Места ремонта:
1. верфь;
2. плавучая верфь;
3. орбитальная станция с модулем ремонта;
4. корабль обеспечения;
   - в бою ремонтирует медленно.

Стоимость ремонта:
- железо;
- время;
- энергия.

Ускорение ремонта:
- инженером;
- золотом, в рамках анти-pay-to-win ограничений.

Редкие технологии:
- могут давать огромным и редким кораблям модули с регенерацией вне боя.

#### 9.3 Запекание: три слоя

Запекание — это серверный предварительный расчёт боевых характеристик до боя.

##### Слой 1 — корабль

Корабль — атом запекания характеристик.

Запекается при постройке или апгрейде, не в бою.

Состав запекания корабля:
- базовые характеристики корпуса и секций;
- суммарные пулы энергетической брони, обычной брони и HP;
- оружие: DPS для малого и среднего оружия, отдельные выстрелы для крупного и сверхкрупного;
- скорость, масса, энергия;
- установленная ИИ-карточка;
- сверхтехнология, если корабль является её носителем.

Триггеры перезапекания:
- апгрейд проекта на верфи;
- исследование технологии;
- изменение состава флота.

Ремонт не перезапекает характеристики.  
Ремонт только восстанавливает пулы.

##### Слой 2 — эскадрилья

Эскадрилья — боевая единица для малых и средних кораблей.

Ключ группировки:

```text
проект + ИИ-карточка + флот
```

Если тот же проект получает другую ИИ-карточку, это уже другая эскадрилья.

Учёт точный:
- сервер считает все корабли без сокращений;
- эскадрилья — компактное представление одинаковых кораблей;
- это не аппроксимация и не упрощение числа кораблей.

Внутри эскадрильи учитываются:
- число кораблей;
- совокупные пулы;
- раненые корабли;
- потери как производная от пула.

Выход из боя:
- бросок делается по каждому кораблю;
- эскадрилья делится на выходящую и оставшуюся части.

##### Слой 3 — одиночные юниты

Одиночные юниты никогда не группируются.

К ним относятся:
- крупные корабли;
- мега-корабли;
- уникальные корабли;
- титаны;
- носители сверхтехнологий;
- танки;
- корабли обеспечения;
- корабли космического десанта;
- трофеи.

У них:
- индивидуальные L/XL выстрелы;
- абордаж;
- смерть-триггеры;
- отдельные визуальные и боевые события.

##### Флотилия

Флотилия — контейнер модификаторов.  
Она запекается на систему.

Состав запекания флотилии:
- ауры титанов и уникальных кораблей;
- сверхтехнологии;
- лучший союзный бонус на систему;
- модификаторы командующего и доктрины;
- итоговые приоритеты целей;
- суммарные пулы сторон.

Перезапекание флотилии происходит при:
- прибытии флота в систему;
- уходе флота из системы;
- смерти носителя ауры;
- выходе стороны из боя.

Если сторона выходит из боя:
- у вышедшей стороны снимаются ауры титанов и уникальных кораблей;
- мощь оставшихся пересчитывается с учётом ушедших.

#### 9.4 Визуальные лимиты и токены

Лимиты отображения зависят от класса кораблей и уровня графики.

Базовая таблица:

| Уровень графики | Малые | Средние | Крупные | Мега и уникальные |
|---|---:|---:|---:|---|
| Low | 60 | 20 | 8 | всегда все |
| Medium | 90 | 30 | 10 | всегда все |
| High | 120 | 40 | 12 | всегда все |
| Ultra | по балансу | по балансу | по балансу | всегда все |

Если реальное число кораблей выше лимита:
- совокупная мощь делится на разрешённое число визуальных токенов;
- токен = N реальных кораблей;
- HP токена = сумма HP входящих кораблей;
- токен умирает целиком;
- из остатка появляется новый токен;
- вооружение токена отображается усреднённо.

Запрещено:
- визуально увеличивать токен сверх запечённого;
- визуально менять состав сверх запечённого.

Общее разрешённое число кораблей одного игрока в бою:
- при превышении лимита уникальные, огромные и крупные корабли отображаются всегда;
- средние и малые агрегируют мощь остальных в оставшееся разрешённое количество.

Эскадрилья визуально:
- отображается как 2–4 модели в зависимости от кратности превышения.

Числа над эскадрильями и токенами:
- по `left-alt`;
- или по настройке:
  - всегда;
  - по модификатору;
  - по клику.

Анимации:
- прибытие — эффект гиперпрыжка;
- уничтожение — взрыв и плавное падение обломков в космосе.

### 10. Флоты

#### 10.1 Режимы флота

Режимы:
- бомбардировка;
- бой;
- следование;
- стоянка.

Если флот ввязался в бой:
- режим принудительно переключается на «бой».

#### 10.2 Содержание флота

Флот потребляет энергию.  
Содержание растёт с размером флота.

Дефицит энергии:
- даётся 30 игровых дней на исправление;
- 1 игровой день = 1 час реального времени;
- стартует событие;
- по окончании события флот распускает корабли, чтобы выйти в плюс.

Распущенные корабли:
- превращаются во враждебных пиратов;
- появляются с краю системы, где стоял флот;
- роспуск идёт сначала среди малых кораблей, затем более крупных.

Газ:
- тратится только на прыжки;
- в бою не влияет.

#### 10.3 Выход из боя

Приказ «отступление» отдаётся всему флоту.

Выход из боя возможен, но:
- у выходящей стороны убираются бонусы титанов и уникальных кораблей;
- у другой стороны бонусы не снимаются.

Малые и средние корабли:
- имеют рандомный шанс неудачи выхода;
- чем слабее класс, тем выше процент неудачи.

Крупные корабли:
- выходят всегда, если не уничтожены физически.

Принцип:

```text
Потерять можно больше, уничтожить меньше.
```

Вышедшие корабли:
- скрытно летят на привязанную верфь;
- если привязки нет, летят на ближайшую союзную или нейтральную верфь;
- HP в пути не обновляются.

Видимость спасшихся:
- при поражении — только когда флот прибыл на верфь;
- уведомление:
  ```text
  из боя вышли: N кораблей, состояние, прибытие
  ```
- при победе — сразу.

#### 10.4 Союзные флоты

Бонусы союзных флотилий никогда не складываются.

Правило:
- выбирается один лучший бонус на всю систему;
- он действует для всех союзников, находящихся в системе или ведущих бой.

Запекание:
- проходит на всю систему;
- переопределяется при появлении новых флотов.

### 11. Бой

#### 11.1 Триггер и место боя

Триггер:
- первый самый дальний выстрел по любому кораблю флотилии вытягивает обе флотилии в бой.

Место:
- бой происходит на карте созвездия;
- бой идёт в тактической зоне;
- орбитальное движение планет является фоном и не влияет на бой.

#### 11.2 До боя: разведка

До боя враг видит:
- приблизительную мощь флота.

Точный состав:
- виден только через разведку или шпионаж;
- с шансом успеха.

Технологии разведки и контрразведки:
- изучаются сколько угодно раз.

#### 11.3 В бою: юниты и урон

Боевые юниты:
- эскадрильи малых и средних кораблей;
- одиночные крупные и особые юниты.

Оружие:
- S/M оружие = запечённый DPS по полосам;
- L/XL оружие = отдельные выстрелы.

Боезапас и энергия:
- в бою бесконечны.

#### 11.4 Приоритеты, инструкции, танкование

ИИ-инструкции флота до боя:
- «атаковать такие цели в первую очередь»;
- «защищать объект или класс».

Они запекаются как override приоритетов целей.

Провокация, аггро, таунт:
- пока танк жив, враги считают его приоритетной целью.

Перенаправление урона:
- X% урона по сопровождаемым союзникам уходит в танк;
- предохранитель: не более 30% HP танка за тик;
- излишек остаётся на цели;
- если танк умер, перенаправление выключено.

Продвинутая технология танков:
- позволяет забирать процент урона на себя;
- всё запекается до боя.

#### 11.5 Сверхтехнологии в бою

Сверхтехнологии не стакаются.

Правило:
- лучшая сверхтехнология на систему среди своих и союзников считается единственной при запекании.

Стек по мощности:
- если умер или ушёл носитель лучшей сверхтехнологии, активируется следующая, более слабая.

Пример:
- подавитель прыжков: вражеские флоты в системе заряжают прыжок дольше, пока жив носитель.

#### 11.6 Заражение королевой в бою

Заражение королевой предотвратить нельзя.

Правило:
- если королева заражает корабль, он заражается.

Для огромных кораблей:
- в ИИ-карточках выбирается карта самоуничтожения заражённых;
- карта срабатывает только после захвата более 50% корабля.

Технология карты:
- чем выше технология карты, тем выше урон по заражённым;
- это сверхтехнология на своём или союзном корабле;
- разрабатывается фракциями для глав альянса.

Визуал заражения:
- смена цвета;
- нарастание биомассы.

#### 11.7 После боя

Обломки:
- собираются сборщиками;
- без сопровождения есть риск.

Ремонт:
- по правилам раздела 9.2.

Реплеи:
- все бои записываются;
- реплеи хранятся на сервере;
- доступен шеринг.

### 12. ИИ-карточки и доктрины

#### 12.1 Карточки алгоритмов

Карточки могут содержать:
- один аспект;
- несколько аспектов.

Одноаспектные карточки:
- бесплатны;
- доступны всегда.

Многоаспектные карточки:
- открываются через исследования;
- есть исследования, которые улучшают карточки или открывают их появление.

Технология объединения карточек:
- можно объединить 2, 3 или 4 карточки;
- объединённая карточка занимает 1 слот;
- содержит аспекты компонентов;
- компоненты расходуются.

Грейд карточек:
- опыт командующего + минералы;
- каждый уровень даёт микропроцент к аспектам;
- повышает эффективность и успешность аспектов.

#### 12.2 Аспекты ИИ корабля

Разрешённые аспекты:
- дистанция ведения боя: ближняя / средняя / дальняя / динамическая;
- приоритет целей, то есть фокус-огонь;
- поведение при атаке противника;
- охранение: не отрываться от носителя, мега-корабля или объекта;
- реакция на абордаж: приоритет защиты отсеков.

Сознательно отсутствующие аспекты:
- отступление отдельного корабля;
- экономия энергии или боезапаса;
- уклонение от метеоритов и обломков;
- преследование убегающих;
- реакция на перевес или недовес сил.

Причины:
- отступление возможно только приказом всему флоту;
- боезапас и энергия в бою бесконечны;
- окружение не влияет на бой;
- поведение должно быть предсказуемым и управляемым.

#### 12.3 Доктрина флота

Командующий качается и может улучшать корабельные ИИ.

Доктрина переопределяет корабельные ИИ:
- общая дистанция и формация;
- фокус огня;
- авто-охранение ценных кораблей;
- приказ:
  - атака по усмотрению;
  - держать позицию;
  - прикрывать;
- момент активации сверхтехнологий:
  - автоматически;
  - вручную.

Доступность:
- две базовые доктрины доступны сразу;
- остальные открываются исследованиями.

Ограничение:
- менять доктрину и ИИ можно только до боя;
- в бою доступен только приказ «отступление» всему флоту.

Приоритет управления:

```text
приказ в бою > доктрина > ИИ корабля > дефолт
```

Адмирал:
- даёт +1 слот алгоритма ИИ за каждые N уровней.

### 13. Бомбардировка и урон планете

#### 13.1 Режимы бомбардировки

Порядок:
1. выбрать флот;
2. направить на планету;
3. включить режим бомбардировки.

Режимы:
- точечный: здания и оборона;
- террор: население;
- тотальный: всё.

Если флот ввязался в бой:
- режим переключается на «бой».

#### 13.2 Визуал бомбардировки

- Корабли висят над планетой.
- На поверхности происходят мини-взрывы.
- Население тает в численности.
- Обороняющиеся теряют жизни и погибают постепенно.

#### 13.3 Здания под огнём

У здания есть:
- уровни;
- HP.

Чем выше уровень, тем больше HP.

Если HP падает до нуля:
- здание становится на уровень ниже;
- HP сбрасывается до максимума нового уровня;
- выработка соответствует текущему уровню.

Если все уровни упали:
- появляется нерасчищенный квадрат:
  ```text
  Разрушенная постройка
  ```

#### 13.4 Нерасчищенные квадраты

Нерасчищенные квадраты — data-driven сущности.

Базовые типы:
- обломки — расчищаются сразу;
- токсичные — требуют технологию;
- кратеры — требуют технологию;
- биозаражение — требует технологию;
- горы;
- останки древней цивилизации;
- животная фауна;
- магнитные поля;
- природные явления;
- деревья.

Список открыт:
- новый тип = новый ассет;
- движок не правится.

Расчистка:
- даёт лом;
- количество лома зависит от типа квадрата.

Штраф бомбардировки:
- каждая 5-я расчистка исчезает;
- навсегда уменьшает лимит построек планеты.

---

### 14. Абордаж

Абордаж инициирует только корабль космического десанта класса мега.

Отображение:
- 2D-схема отсеков корабля;
- двери;
- пробоины;
- утечка кислорода;
- сила дверей;
- экипаж в каждом модуле.

Отсеки:
- лечения;
- рубка;
- моторный отсек;
- вооружение;
- выработка кислорода.

Механики:
- стравливание кислорода доступно обеим сторонам;
- заваривание дверей — временная преграда;
- заваривание тратит время атакующего;
- уничтожение каждого отсека влияет на корабль и на бой внутри корабля.

Авторазрешение:
- игрок задаёт приоритеты;
- например:
  - захват рубки;
  - захват двигателя;
  - захват оружия.

Успех зависит от:
- численности десанта;
- защиты корабля;
- характеристик специалистов.

Итог успеха:
- захваченный корабль становится трофеем;
- трофей имеет повреждения;
- часть отсеков может быть безвозвратно уничтожена;
- трофей слабее и дешевле исходного корабля;
- трофей требует ремонта;
- трофей можно продать.

---

### 15. Наземные операции

Армия:
- состоит из отрядов;
- отряды имеют состав:
  - пехота;
  - техника;
  - десантные модули;
- аналог флота из кораблей.

Поверхность планеты:
- делится на зоны;
- зоны имеют линию фронта;
- линия фронта двигается.

Последовательность:
1. точка высадки;
2. рубежи обороны;
3. столица.

Расчёт:
- сервер считает бой;
- клиент показывает 2D-визуализацию.

После захвата планеты с населением:
- появляется «неспокойность»;
- подавляется гарнизоном.

Безжизненные планеты:
- контроль не нужен;
- оккупация происходит автоматически по прибытии флота;
- если нет вражеского флота или обороны.

Эвакуация армии:
- транспорт поднимает войска за N секунд;
- во время подъёма войска уязвимы;
- условия:
  - транспорт жив;
  - орбита не контролируется врагом полностью.

### 16. Исследования

#### 16.1 Аспекты и пулы

Все исследования делятся на аспекты:
- физические;
- социологические;
- вооружение;
- корабли:
  - корвет — первый и бесплатный;
  - остальные классы открываются зависимыми исследованиями;
- секции кораблей:
  - крутые секции тоже могут выпадать в выборе исследований.

Пулы аспектов раздельные.

Предрасположенность учёного даёт бонус скорости к своему аспекту:
- физик быстрее исследует физические;
- социолог быстрее исследует социологические;
- военный специалист быстрее исследует вооружение и военные направления.

#### 16.2 Постоянные технологии и ветки

Постоянные технологии:
- находятся вне веток;
- не сгорают;
- доступны всегда.

Примеры постоянных технологий:
- корвет;
- врата;
- структуры древних;
- базовые элементы выхода на глобальную карту.

Веточные технологии:
- на каждый уровень исследований рандомно даются 3 варианта на каждый аспект;
- изучить можно только один вариант;
- два невыбранных варианта сгорают на этом уровне;
- сгоревшие варианты могут выпасть на поздних уровнях, если они не ключевые.

Принцип закрытия альтернативы:
- старый принцип «выбор плазмы закрывает кинетику» реализуется через драфт;
- выбор одного направления закрывает альтернативу на текущем уровне.

Исследования меняют направление фракции:
- техно-уклон;
- военно-уклон;
- экономический уклон.

#### 16.3 Эвентовые технологии

Существуют технологии, привязанные к эвентам.

Примеры:
- миграция;
- вторая очередь исследований;
- защитные технологии против глобального ИИ.

Правило:
- эвентовые технологии доступны только пока идёт соответствующий эвент.

#### 16.4 Очередь исследований

Очередь исследований одна.

Вторая очередь:
- возможна только во время глобального эвента злобного ИИ;
- не покупается за золото.

#### 16.5 Сброс веток

Сброс веток возможен, но дорог.

Ориентир:
- примерно 1 раз за сезон.

После сброса:
- все веточные исследования начинаются заново;
- постоянные технологии остаются.

#### 16.6 Учёные

Учёный слегка ускоряет исследование.

Предрасположенности:
- физик;
- социолог;
- военный специалист.

Назначение:
- можно назначить учёного в лабораторию планеты — это даёт бонус к очереди;
- на исследовательском корабле учёный обязателен.

Исследовательский корабль:
- учёный повышает квалификацию и уровень в том, что делает;
- если учёный погиб, корабль теряет способность исследовать;
- замена учёного в полёте возможна.

Ветвистая прокачка учёного под эвенты:
- раскопки;
- изучение галактик;
- изучение аномалий;
- изучение угасших империй;
- изучение левиафанов.

#### 16.7 Совместные исследования

Совместные исследования существуют только на глобальный эвент защиты от ИИ.

Правило:
- объединение альянсов ускоряет изучение;
- все участники объединения получают эти технологии.

Вне эвента совместных исследований нет.

#### 16.8 Бесконечные технологии

Разведка и контрразведка изучаются сколько угодно раз.

Формат:
- уровни-стаки;
- каждый уровень улучшает соответствующую механику.

#### 16.9 Технологии ускорения

Технологии ускорения:
- выбиваются только из враждебного ИИ;
- могут продаваться на рынке за золото.

### 17. Специалисты

#### 17.1 Типы

Типы специалистов:
- адмирал;
- флотоводец;
- учёный;
- инженер;
- шпион;
- государственник.

Назначения и роли берутся из FAQ v9.0.

Правила смерти, клонов и страховки берутся из FAQ v9.1.

#### 17.2 Лимит

Лимит активных специалистов равен уровню командного центра.

#### 17.3 Смерть и клон

Базовое правило:
- выжил / не выжил;
- шанс 50/50;
- уровень специалиста не меняет базовый шанс;
- ранений в базовом правиле нет.

Во время глобального противостояния или эвента злобного ИИ:
- шанс выживания повышается;
- появляется третий исход — ранение.

Если специалист умер:
- можно купить клон за деньги;
- клон сохраняет те же характеристики;
- клон не теряет навыки и не меняет параметры.

Страховка:
- покупается за золото;
- после смерти специалист возвращается через таймер.

Сезонное сохранение:
- все купленные за золото специалисты сохраняются на следующий сезон;
- сохраняются даже если погибли в финальном бою.

#### 17.4 Прокачка и роли

Специалисты получают опыт только через действия.

Запрещено:
- автоматическая прокачка без действий.

У всех специалистов есть ветвистая прокачка под разные эвенты.

Адмирал:
- командует флотом;
- даёт +1 слот алгоритма ИИ за каждые N уровней;
- командующий качается и может улучшать корабельные ИИ;
- связан с доктринами флота.

Флотоводец:
- бонус к скорости и манёвру;
- улучшает шанс выхода из боя.

Инженер:
- бонус к строительству;
- ускоряет ремонт.

Государственник:
- может находиться только на планете или столице;
- даёт бонусы государства.

Шпион:
- см. раздел 21.

#### 17.5 Принцип монетизации

Главный принцип:

```text
Наша задача — сделать интересную игру, а не заработать.
```

Специалисты:
- могут покупаться за игровую валюту или золото;
- не должны давать прямое pay-to-win преимущество в бою.

### 18. Экономика

#### 18.1 Ресурсы

Основные ресурсы по FAQ v9.0:
- железо;
- минералы;
- газ;
- золото.

Кредиты:
- игровая валюта;
- источники:
  - рынок;
  - торговля;
  - здания;
  - задания.

#### 18.2 Энергия

Здания на планете потребляют энергию.

При дефиците энергии:
- производство пропорционально проседает;
- электростанция является ключевым зданием.

Флот тоже потребляет энергию.

Дефицит энергии флота:
- 30 игровых дней на исправление;
- 1 игровой день = 1 час реального времени;
- по окончании события флот распускает корабли;
- распущенные корабли превращаются во враждебных пиратов;
- роспуск идёт сначала среди малых кораблей, затем более крупных.

#### 18.3 Газ

Газ тратится только на прыжки.

В бою газ не влияет.

Расход газа:
- функция числа кораблей и дистанции;
- точные формулы — баланс.

#### 18.4 Формулы роста уровней

Стоимость:

```text
cost(level) = baseCost * 1.5^level
```

Время:

```text
time(level) = baseTime * 1.4^level
```

Бонус:

```text
bonus(level) = baseBonus * level * (1 + level * 0.01)
```

Эти формулы являются базовыми по FAQ v9.0.  
Точные коэффициенты могут балансироваться, но структура роста сохраняется.

#### 18.5 Лом и расчистки

Расчистка квадрата даёт лом.

Количество лома зависит от типа квадрата.

Обломки боя:
- собираются сборщиками;
- без сопровождения есть риск;
- другие игроки могут уничтожить сборщика и забрать лом.

### 19. Рынок

#### 19.1 Цены

Локальные цены:
- формируются по спросу и предложению внутри галактики.

Глобальный средний индекс:
- существует справочно;
- помогает понимать общий уровень цен.

#### 19.2 Форматы торговли

Доступны:
- торговля между игроками;
- аукционы;
- обмен ресурсов.

#### 19.3 Комиссия

Торговцы:
- стартуют без комиссии;
- развитие их торговой площадки даёт им иные торговые бонусы.

Остальные фракции:
- комиссия снижается по мере развития торговой площадки Торговцев в галактике;
- Торговцы полезны всем, потому что их инфраструктура снижает издержки рынка.

#### 19.4 Налог альянса

Глава альянса может установить налог.

Потолок налога:
- 10%.

#### 19.5 Анти-pay-to-win

Запрещено:
- продавать ресурсы за золото напрямую.

Разрешено:
- технологии ускорения могут продаваться на рынке за золото;
- эти технологии выбиваются только из враждебного ИИ.

---

### 20. Торговые караваны

#### 20.1 Автомаршруты

Торговый маршрут:
- соединяет две системы;
- в системах должна быть точка торговли или рынок.

Торговые корабли:
- летают автоматически по циклу;
- приносят кредиты за завершённый круг.

#### 20.2 Риск и эскорт

Караван могут перехватить:
- пираты;
- вражеские игроки.

Эскорт:
- свой флот сопровождает караван;
- сопровождение снижает шанс перехвата.

#### 20.3 Лимиты

Число маршрутов зависит от:
- уровня рынка;
- технологий.

Торговцы:
- получают +1 маршрут;
- имеют более быстрые торговые корабли.

#### 20.4 Разовый конвой

Игрок может вручную отправить ценный груз.

Особенности:
- выше прибыль;
- выше риск;
- требуется сопровождение;
- это операция с эскортом, а не автокараван.

### 21. Шпионаж и дипломатия

#### 21.1 Миссии шпиона

Шпион может выполнять миссии:
- разведка флота;
- разведка системы;
- саботаж здания;
- саботаж корабля;
- кража ресурсов.

Убийств специалистов нет.

Смерть специалиста:
- возможна только по базовой механике 50/50;
- во время специальных эвентов могут действовать изменённые исходы;
- провал миссии не является гарантированным убийством.

#### 21.2 Контрразведка

Шансы успеха шпионажа зависят от:
- уровня шпиона;
- контрразведки цели;
- технологий;
- собственных шпионов защиты.

Разведка и контрразведка:
- изучаются сколько угодно раз.

Шпионы высокого уровня:
- могут проводить разведку ИИ;
- разведка ИИ несёт угрозу уничтожения шпиона.

#### 21.3 Война и мир

Война может быть объявлена в любой момент.

Дебаф агрессора:
- зависит от разницы рейтинга силы;
- полный список дебафов задаётся FAQ v9.0 и углубляется FAQ v9.1.

Дипломатические состояния:
- война;
- мир;
- нейтралитет;
- торговые соглашения.

Мирный договор может содержать условия:
- репарации;
- передача систем;
- срок перемирия.

### 22. Население

#### 22.1 Единый ресурс

Население — единый ресурс.

Нет разделения на:
- рабочих;
- учёных;
- солдат;
- другие специализированные типы населения.

#### 22.2 Уровень жизни вместо счастья

Вместо счастья используется уровень жизни.

Уровень жизни:
- зависит от зданий;
- влияет на рост населения;
- влияет на выработку.

#### 22.3 Потребность зданий

Каждое здание и уровень здания требует определённое число населения для 100% выработки.

Если населения недостаточно:
- выработка здания снижается;
- точная формула — баланс.

#### 22.4 Рост

Население растёт постепенно.

Рост зависит от:
- уровня жизни;
- исследований генетики;
- дебафов;
- эвентов.

Миграция:
- вручную транспортом;
- через эвенты переселения.

Потери населения:
- метеориты от уничтожения спутников уничтожают часть населения;
- дебаф агрессора уменьшает прирост населения;
- бомбардировка в режиме террора уменьшает население.

### 23. События и аномалии

#### 23.1 Трей и показ

События лежат в трее игры, видимы; важные не ограничены по времени.

Комбинированный показ:

| Тип события | Показ |
|---|---|
| Мелкая аномалия | карточка справа |
| Раскопки | карточка + панель прогресса |
| Левиафан | полноэкранное предупреждение |
| Угасшая империя | цепочка с портретом и выборами |
| ИИ-апокалипсис | глобальный экран события |

#### 23.2 Аномалии и цепочки

Аномалии — одноразовые по seed; текстовые квесты с бонусами.

Цепочки:
- одно событие ведёт к другому;
- разные выборы дают разные только бонусы.

Изучают аномалии и проводят раскопки только исследовательские корабли.

#### 23.3 Аборигены и червоточины

Аборигены:
- исследовать;
- захватывать;
- не вмешиваться.
Разные подходы дают разные бонусы.

Временные/нестабильные червоточины:
- могут отправить флот в случайный эвент или далёкую галактику.

#### 23.4 Пираты

- Базы — в скрытых системах;
- если не зачищать — волны растут.
- Рейды, засады.

#### 23.5 Левиафаны

- Не респаунятся в сезоне;
- новые — только эвентами.
- Уничтожают планеты и спутники;
- требуют подготовки.

#### 23.6 Угасшие империи

- Могут «проснуться» в середине сезона — глобальный эвент.
- Уникальные технологии, цепочки событий, могут быть опасны.

#### 23.7 Глобальные эвенты «фронт и тыл»

База: волна ИИ затрагивает всех; между волнами — фоновые мелкие рейды.

Роли по удалённости:
- Передовая: эвенты обороны/атаки; крупные игроки получают другие задачи, повышающие характеристики, число кораблей и т.п.
- Дальний тыл: выпадает исследование, помогающее передовой, либо передача флота на передовую, оформленная как исследование (визуал — автоматический прямой полёт).
- Торговцы: переводят на торговых судах оружие, отданное другими игроками (лучшее отданное — в приоритете).

Передача технологий: возможна, но чем дальше и чем больше разница, тем дольше.

Помощь переезда столиц передовой / отправка кораблей: выпадает игрокам середины, качающим выбранную технологию по ветке своей фракции, чей лидер выбрал схожую ветку развития.

Без фракции: игрок выбирает всё сам.

Очки считаются всем.

Дополнительные эвенты:
- «Конвой снабжения» — тыл формирует конвой, эскорт до передовой, перехваты пиратами/ИИ, доставленное = бонус фронту.
- «Эвакуация науки» — передача данных лабораторий/учёных с риском потери.
- «Крепость» — тыл вкладывает ресурсы в оборонительную линию фронтовой системы; вклад = престиж.
- «Ретранслятор» — цепочка станций связи тыл→фронт: видимость, скорость зарядки прыжков.
- «Общий котёл» — тыл отчисляет % выработки в пул, распределение фронту по рейтингу вклада.
- «Мемориал» — после крупного боя участники получают эвент с наградой престижа; формирует историю сезона.

### 24. ИИ-угроза

#### 24.1 Глобальный ИИ-враг

- Враждебен всем, растёт со временем, уникальные корабли.
- С него падают редкие чертежи и технологии ускорения.
- Дальше от новичков, чем от старичков.
- Даёт игрокам победы, интересные бои, крутые технологии.

#### 24.2 Формат давления

Волны с эскалацией + фоновые мелкие рейды между волнами.

#### 24.3 Юниты ИИ

- Левиафаны — уничтожают планеты и спутники;
- королевы — заражают корабли, беря их под свой контроль;
- суицидники — как зерги из StarCraft: мало урона, их много, биологическое моно-сознание, уничтожающее и поглощающее всё на своём пути.

#### 24.4 Королева: заражение

- Предотвратить нельзя: заражает — значит заражает.
- Для огромных кораблей в ИИ-карточках выбирается карта самоуничтожения заражённых; срабатывает только после захвата более 50% корабля.
- Чем выше технология карты, тем выше урон по заражённым; это сверхтехнология своего или союзного корабля; разрабатывается фракциями для глав альянса.
- Визуал: смена цвета, нарастание биомассы.

#### 24.5 Ветки развития ИИ

- Развитие ИИ — чистый рандом;
- в определённый момент ИИ создаёт технологию червоточин в закрытые галактики.

#### 24.6 ИИ и новички

- Грозный ИИ может войти в систему новичка как эвент, но не уничтожить новичка.

### 25. Защита новичков

#### 25.1 Спавн

- Рандомное место, 25–45 клеток до ближайших игроков, рядом нет старичков.
- Система новичка скрыта и опасна для изучения; вышедшие на глобальную карту игроки не могут в неё войти.

#### 25.2 Дебафы агрессора

Если сильный игрок атакует слабого и разница рейтинга силы выше порога:
- торговцы не взаимодействуют;
- злой ИИ повышает внимание;
- покупки за золото дороже на процент;
- дебаф на время;
- уменьшается прирост населения.

#### 25.3 Агрессор в альянсе

- Уведомление главе;
- не вышиб → дебаф на альянс (торговля только внутри альянса, небольшой % с торговли копится альянсу);
- дебаф прироста населения на альянс не распространяется.

Накопление: новые проштрафившиеся → +процент на альянс, время дебафа обновляется.

---

### 26. Альянсы и социалка

#### 26.1 База

- Союзы, совместные флоты, общие войны;
- полная общая видимость карты и флотов союзников в реальном времени.

#### 26.2 Лимит и выбор главы

- Лимит участников (старт ~30, потолок ~50) расширяется только через ветку альянса.
- Альянс зарабатывает очки развития общей активностью (войны, исследования, эвенты).
- Глава выбирает, куда их вкладывать: своё личное развитие (его бонусы) или технологии альянса (лимит, общие ауры).
- Расширение лимита = жертва личной прокачкой → внутренняя политика альянса.

#### 26.3 Налог

Глава ставит %; потолок 10%.

#### 26.4 Ветки развития альянсов (эндшпиль)

- Транспортировка/миграция;
- планетарная оборона;
- планетарный ремонт;
- силовые верфи;
- шпионские технологии мега-уровня;
- выжженная земля;
- мега-запечатывальщики.

Выбор по большинству прокачки; глава выбирает направление альянса.

#### 26.5 Выбранный главой игрок

- Получает больший процент флота;
- выбирает варианты в цепочке поздних эвентов, за которые другие голосуют путём изучения.

#### 26.6 Территория переселения

- Общим голосованием выбирается игрок (переселившийся дальше всех, с более высоким уровнем развития);
- у него создаётся территория переселения;
- все перемещаются каждый в свою систему;
- получают все его технологии;
- выжившие флоты делятся по опыту.
- Хозяин территории получает компенсацию: престиж + % ресурсов альянса на время эндшпиля.

#### 26.7 Чат

- Глобальный;
- альянс;
- локальный (галактика);
- непосредственный (личный/комната).

---

### 27. Сезон и эндшпиль

#### 27.1 Фазы

Развитие → эскалация → апокалипсис, ориентир 60/25/15% длительности; сезон 3–6 месяцев.

#### 27.2 Миграция

- Только при высоком уровне близости/нападения Злобного ИИ;
- только через технологию, даваемую альянсам под угрозой;
- мигрирует часть технологий и построек.

#### 27.3 Эвенты обороны

- Изучения;
- исследования;
- победы над определённым флотом;
- защиты исследовательской системы;
- прорыва и изучения останков флота ИИ после победы.

#### 27.4 Победа над ИИ

Победа = завершение сезона с итогами и ранним рестартом. «Победа возможна, но какой ценой?»

#### 27.5 Итоги и награды

- Запись лучших боёв;
- захваты/отбития планет;
- рейтинг выживших;
- награды: косметика, престиж, уникальные специалисты.

#### 27.6 Перезапуск

Мир перезапускается; купленные за золото специалисты (даже погибшие в финальном бою), престиж и косметика сохраняются.

#### 27.7 Престиж

Между сезонами даёт маленький стартовый бонус, не pay-to-win.

---

### 28. Монетизация

#### 28.1 Принцип

«Наша задача сделать интересной игру, а не заработать».

#### 28.2 Можно за золото

- Косметика: скины кораблей/планет/UI, рамки ника, след варпа флота;
- специалисты;
- страховка;
- клоны;
- небольшое ускорение.

#### 28.3 Ускорения

Потолок 2 часа в сутки суммарно.

#### 28.4 Боевой пропуск

Нет. Только косметические наборы.

#### 28.5 Нельзя

Прямое преимущество в бою; ресурсы за золото напрямую.

#### 28.6 Агрессор

Стоимость покупок за золото повышается на процент (часть дебафов, раздел 25).

### 29. Производительность, мобильные, тех

#### 29.1 Уровни графики

Low / Medium / High / Ultra (таблица эффектов и dpr — v9.0, раздел 19).

#### 29.2 Автопонижение

При просадке FPS — автопонижение уровня, с уведомлением и возможностью отключить.

#### 29.3 Управление

Мобильные: тап / пинч / свайп / лонг-тап.
ПК: настраиваемые горячие клавиши; left-alt — числа эскадрилий.

#### 29.4 Стек и оптимизация

- Карты 1/2/4 — Canvas псевдо-3D;
- созвездие и бой — WebGL (R3F);
- InstancedMesh;
- drei Stars;
- тени отключены.
- Запекание характеристик (Часть 2, 9.3) и визуальные лимиты (Часть 2, 9.4) — основная оптимизация боёв.
- Перспектива: PWA / Capacitor.

### 30. Мета

#### 30.1 Туториал

Сюжетная цепочка с наставником-учёным; длительность без жёсткого лимита (может быть дольше 30–40 минут); заканчивается выходом из скрытой системы.

#### 30.2 Задания

Ежедневные / еженедельные / сезонные.

#### 30.3 Рейтинги и лиги

Рейтинги: сила, наука, торговля, флот + рейтинг альянсов; лиги по силе.

#### 30.4 Достижения

Система достижений — в мета-слое сезона.

### 31. Дополнения к предыдущим частям (пропущенные фиксации)

- Врата при потере столицы (захват/уничтожение): переходят на автономное питание, скорость ×0.5.
- Станция захвата: строитель убит → недостроенная станция исчезает; станция захвата превращается в верфь / оборонительную платформу / точку торговли, перепрофилируется обратно.
- Скорость флота = скорость самого медленного корабля.
- Корабли без вооружения в системе с врагом всегда автоматически уворачиваются в безопасную систему; набор энергии прыжка и уровень прыжковых двигателей учитываются как у всех.
